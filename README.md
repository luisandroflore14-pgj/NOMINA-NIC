# NominaNIC Pro

Sistema de nómina para Nicaragua en HTML, CSS y JavaScript. Calcula salario, horas extras, antigüedad, vacaciones, INSS, IR, aguinaldo y neto a recibir.

## Uso
1. Abre `index.html` en tu navegador.
2. Registra trabajadores en la pestaña **Registro**.
3. Consulta la nómina agrupada por departamento en la pestaña **Nómina**.

Los datos se guardan en el navegador (localStorage). No se envían a ningún servidor.

## Tecnologías
HTML, CSS y JavaScript.
